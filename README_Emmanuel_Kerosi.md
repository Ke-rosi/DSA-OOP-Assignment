# OOP Foundations for Data Structures Assignment

## 1. What is the role of a class in a linked list?

A class acts as a blueprint for creating objects. In a linked list, classes are used to create nodes and manage the linked list structure and operations.

---

## 2. What is the difference between a node and a linked list?

A node is a single element that stores data and a reference to the next node. A linked list is a collection of connected nodes.

---

## 3. Why do we use None in next?

None shows that a node is not connected to another node. The last node in a linked list usually points to None to show the end of the list.

---

## 4. How is a linked list different from a Python list?

A Python list stores elements in contiguous memory locations, while a linked list stores elements as separate nodes connected using references. Linked lists are better for insertions and deletions.

---

## 5. Why is OOP useful for data structures?

OOP helps organize code using classes and objects. It makes data structures reusable, easier to manage, and easier to understand.
